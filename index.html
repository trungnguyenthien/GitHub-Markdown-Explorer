Cách tạo GitHub Personal Access Token (PAT)

          
Mã PAT giúp ứng dụng kết nối an toàn với GitHub API.

          
          

            
1

            

              Tạo Token trên GitHub:
              
Nhấp nút bên dưới để mở trang tạo Token với cấu hình điền sẵn:

              
                
                Mở trang tạo PAT GitHub
              
            

          


          

            
2

            

              Chọn quyền (Scopes):
              
Tích chọn quyền repo (nếu cần xem repo riêng tư) hoặc public_repo.

            

          


          

            
3

            

              Sao chép Token:
              
Cuộn xuống cuối trang bấm Generate token, sao chép chuỗi token và dán vào ứng dụng.
