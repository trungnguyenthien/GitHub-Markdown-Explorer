How to create a GitHub Personal Access Token (PAT)

          
A PAT enables a secure connection to the GitHub API.

          
          

            
1

            

              Create Token on GitHub:
              
Click below to open the token creation page with pre-filled scopes:

              
                
                Open GitHub PAT Creation Page
              
            

          


          

            
2

            

              Select Permissions (Scopes):
              
Check the repo scope (for private repos) and gist scope (for cloud backups).

            

          


          

            
3

            

              Copy Token:
              
Scroll down and click Generate token, then copy and paste the token string into the app.
