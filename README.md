# 📱 GitHub Markdown Explorer

**GitHub Markdown Explorer** là ứng dụng web di động giúp bạn duyệt, quản lý và đọc các tài liệu Markdown (`.md`) từ các kho lưu trữ GitHub một cách dễ dàng, mượt mà và hỗ trợ đọc ngoại tuyến không cần mạng.

🌐 **Trải nghiệm ứng dụng ngay tại**:  
👉 **[https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/](https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/)**

---

## 🌟 Chức Năng Nổi Bật

- 📱 **Giao diện di động tiện lợi**: Thanh 5 Tab điều hướng cố định dưới đáy màn hình giúp thao tác bằng 1 tay:
  - 📄 **Fav Page**: Quản lý bài viết yêu thích & nút đồng bộ làm mới dữ liệu.
  - ⭐ **Fav Repo**: Truy cập nhanh các kho lưu trữ đã đánh dấu sao.
  - 📁 **All Repo**: Tìm kiếm & xem tất cả các kho lưu trữ (tự động ghim các kho yêu thích lên đầu).
  - 🕒 **History**: Xem lại lịch sử các bài đã đọc (bài đọc gần nhất tự động ở trên cùng).
  - 📖 **Reader**: Trình đọc bài viết hỗ trợ chuyển đổi giữa chế độ văn bản và mã nguồn (Raw).
- ⚡ **Đọc ngoại tuyến (Offline)**: Đọc lại toàn bộ nội dung các bài viết đã yêu thích ngay cả khi không có kết nối mạng Internet hoặc đang bật Chế độ máy bay.
- ☀️ **Giao diện sáng dễ đọc**: Màn hình luôn hiển thị màu sáng đồng nhất cho văn bản, bảng biểu, sơ đồ và mã nguồn, giúp đọc tài liệu rõ ràng và không mỏi mắt.
- 📐 **Hỗ trợ sơ đồ & mã nguồn**: Tự động hiển thị các sơ đồ vẽ bằng Mermaid, PlantUML và làm nổi bật cú pháp mã lập trình.
- 🔍 **Tùy chỉnh cỡ chữ**: Nút phóng to/thu nhỏ nội dung văn bản (+ / -) giúp điều chỉnh kích thước chữ vừa mắt nhất.

## 📲 Hướng Dẫn Cài Đặt Ứng Dụng (PWA - Cài Trực Tiếp Từ Trình Duyệt)

Ứng dụng hỗ trợ công nghệ **Progressive Web App (PWA)**, cho phép bạn cài đặt trực tiếp từ trình duyệt web vào máy mà không cần tải từ App Store hay Google Play. Khi cài đặt xong, ứng dụng sẽ có biểu tượng riêng, mở toàn màn hình (không có thanh URL của trình duyệt) và hỗ trợ đọc offline cực kỳ mượt mà.

### 🍎 1. Trên iPhone / iPad (Trình duyệt Safari)
> 💡 *Lưu ý: Trên iOS, bạn cần sử dụng trình duyệt **Safari** để có đầy đủ tính năng PWA.*
1. Mở liên kết trang web bằng **Safari**: [https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/](https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/)
2. Nhấp vào nút **Chia sẻ** (biểu tượng hình vuông có mũi tên hướng lên `⎋` ở thanh công cụ dưới cùng).
3. Cuộn xuống danh sách tùy chọn và chọn **Thêm vào MH chính** (*Add to Home Screen* ➕).
4. Nhấn **Thêm** (*Add*) ở góc trên bên phải. 
5. Biểu tượng ứng dụng sẽ xuất hiện trên màn hình chính của iPhone/iPad.

### 🤖 2. Trên Android (Trình duyệt Google Chrome)
1. Mở liên kết trang web bằng **Chrome**: [https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/](https://trungnguyenthien.github.io/GitHub-Markdown-Explorer/)
2. Nhấp vào biểu tượng **Menu 3 chấm (⋮)** ở góc trên bên phải trình duyệt.
3. Chọn **Cài đặt ứng dụng** (*Install app*) hoặc **Thêm vào màn hình chính** (*Add to Home screen*).
4. Nhấn **Cài đặt** (*Install*) để xác nhận. Ứng dụng sẽ tự động xuất hiện trên màn hình chính và danh sách app của điện thoại.

### 💻 3. Trên Máy Tính Mac / Windows (Trình duyệt Chrome hoặc Edge)
1. Truy cập trang web trên **Google Chrome** hoặc **Microsoft Edge**.
2. Nhìn vào phía bên phải thanh nhập địa chỉ URL, nhấp vào biểu tượng **Cài đặt ứng dụng** (hình màn hình máy tính có mũi tên tải xuống ⬇️ hoặc biểu tượng dấu `⊕`).
3. Nhấp **Cài đặt** (*Install*). Ứng dụng sẽ chạy trong một cửa sổ riêng biệt giống hệt như một phần mềm máy tính thông thường.

### 🖥️ 4. Trên macOS (Trình duyệt Safari - macOS Sonoma trở lên)
1. Mở trang web bằng trình duyệt **Safari** trên Mac.
2. Trên thanh menu trên cùng, chọn **Tệp** (*File*) ➔ **Thêm vào Dock...** (*Add to Dock...*).
3. Nhấn **Thêm** (*Add*). Ứng dụng sẽ xuất hiện trực tiếp trên thanh Dock của macOS và chạy độc lập.

## 🚀 Hướng Dẫn Sử Dụng Nhanh

1. Mở ứng dụng và nhập mã **Personal Access Token (PAT)** từ GitHub (có sẵn hướng dẫn tạo PAT đơn giản trong app).
2. Chọn kho lưu trữ và thư mục chứa tài liệu Markdown bạn muốn đọc.
3. Nhấp biểu tượng **Ngôi sao ⭐** trên bài viết để thêm vào danh sách **Fav Page**.
4. Bài viết yêu thích sẽ tự động được lưu trữ trên thiết bị. Bạn có thể mở lại ứng dụng và đọc lại các bài viết này bất kỳ lúc nào kể cả khi không có kết nối mạng.

## 🔑 Hướng Dẫn Tạo GitHub Personal Access Token (PAT)

Để ứng dụng có thể kết nối với tài khoản GitHub của bạn (duyệt repository, đọc nội dung Markdown và đồng bộ dữ liệu), bạn cần tạo một mã **Personal Access Token (PAT)**:

### Các bước thực hiện:
1. Đăng nhập vào GitHub và truy cập trực tiếp trang tạo token:  
   👉 **[https://github.com/settings/tokens](https://github.com/settings/tokens)**  
   *(Hoặc vào **Settings** ➔ **Developer Settings** ở góc dưới bên trái ➔ **Personal access tokens** ➔ **Tokens (classic)**)*.
2. Nhấn vào nút **Generate new token** ➔ chọn **Generate new token (classic)**.
3. Điền thông tin token:
   - **Note**: Đặt tên gợi nhớ (ví dụ: `GitHub Markdown Explorer`).
   - **Expiration**: Chọn thời hạn hiệu lực (khuyến nghị chọn *No expiration* để không bị gián đoạn khi dùng).
   - **Scopes (Quyền truy cập)**: Tích chọn các quyền sau:
     - ✅ **`repo`** (Full control of private repositories): Cho phép ứng dụng đọc tài liệu trong các repo của bạn (cả Public và Private).
     - ✅ **`gist`** (Create gists): Cho phép ứng dụng đồng bộ/backup danh sách nhóm và trang yêu thích lên GitHub Gist cá nhân của bạn.
4. Cuộn xuống cuối trang và bấm nút **Generate token**.
5. **Sao chép mã Token** vừa tạo (dãy ký tự bắt đầu bằng `ghp_...`) và dán vào ứng dụng.  
   *(⚠️ **Lưu ý quan trọng**: GitHub chỉ hiển thị mã token này đúng 1 lần duy nhất sau khi tạo, hãy sao chép ngay trước khi đóng trang).*

## 🔒 Cam Kết Bảo Mật & Quyền Riêng Tư (Security & Privacy)

Chúng tôi cam kết tuyệt đối về tính an toàn và quyền riêng tư cho người dùng:

- 🛡️ **100% Lưu trữ cục bộ (Local Storage Only)**: Toàn bộ Token và dữ liệu bài viết của bạn **chỉ được lưu trữ duy nhất trên trình duyệt của thiết bị bạn đang dùng** (`localStorage`).
- ⚡ **Kiến trúc hoàn toàn không có máy chủ (Pure Client-Side PWA)**: Ứng dụng hoạt động 100% trên trình duyệt (static web app) được host trên GitHub Pages, hoàn toàn không có backend hay cơ sở dữ liệu trung gian nào. Mọi truy vấn API đều được trình duyệt của bạn gửi trực tiếp và duy nhất tới máy chủ chính thức của GitHub (`https://api.github.com`).
- 🚫 **Tuyệt đối không theo dõi hoặc thu thập dữ liệu**: Mã Token và tài liệu của bạn **không bao giờ** bị gửi tới bất kỳ bên thứ ba hay máy chủ ngoài nào khác.
- 🗑️ **Toàn quyền kiểm soát**: Bạn có thể xóa Token khỏi thiết bị bất kỳ lúc nào tại màn hình cài đặt trong ứng dụng, hoặc thu hồi quyền truy cập của Token trực tiếp trên trang quản lý GitHub Settings bất cứ khi nào bạn muốn.
