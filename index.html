Cách tạo GitHub Personal Access Token (PAT)

          
Mã PAT giúp ứng dụng web kết nối an toàn với GitHub API để đọc danh sách kho lưu trữ và file của bạn.

          
          

            
1

            

              Tạo Token trực tiếp trên GitHub:
              
Nhấp vào nút bên dưới để mở trang tạo Token với cấu hình điền sẵn:

              
                
                Mở trang tạo PAT trên GitHub
              
            

          


          

            
2

            

              Chọn quyền (Scopes):
              
Đảm bảo đã tích chọn quyền repo (Full control of private repositories) nếu bạn muốn xem repo riêng tư, hoặc chọn public_repo nếu chỉ duyệt repo công khai.

            

          


          

            
3

            

              Tạo và sao chép Token:
              
Cuộn xuống cuối trang và bấm Generate token. Sao chép chuỗi token (bắt đầu bằng ghp_) và dán vào ô nhập PAT của ứng dụng.

            

          


          

            
            Cam kết bảo mật: Mã PAT chỉ được lưu trực tiếp trên trình duyệt của bạn (qua localStorage). Ứng dụng này 100% web tĩnh, không sử dụng server trung gian và không lưu trữ token của bạn ở bất kỳ nơi nào khác.
          

        


        
        

          
Các tính năng nổi bật của GitHub Markdown Explorer

          
          

            
⭐ Đánh dấu Yêu thích & Lưu Cache Offline

            
Nhấp vào biểu tượng dấu sao ⭐ ở thẻ Repo hoặc File để đưa vào danh sách yêu thích. Các file yêu thích sẽ **tự động được nạp và lưu vào IndexedDB**, giúp bạn mở đọc tức thì ngay cả khi không có mạng (Offline Mode).

          


          

            
🔄 Đồng bộ tự động & Nút Sync

            
Khi mở một file yêu thích có mạng, ứng dụng dùng cơ chế Stale-While-Revalidate: hiển thị bản cache ngay tức khắc (<100ms), đồng thời âm thầm kiểm tra `SHA` từ GitHub để làm mới nội dung nếu có bản cập nhật. Bạn cũng có thể bấm Sync All để cập nhật tất cả file yêu thích 1 lúc.

          


          

            
🔍 Thu phóng chữ toàn cục (Zoom In / Out)

            
Sử dụng các nút - / 100% / + trên thanh xem file để điều chỉnh phóng to hoặc thu nhỏ chữ (từ 75% đến 200%). Tỷ lệ thu phóng này được áp dụng tự động cho toàn bộ các file Markdown bạn mở.

          


          

            
📊 Render sơ đồ PlantUML & Mermaid

            
Các khối mã ```mermaid và ```plantuml bên trong tài liệu Markdown sẽ tự động được chuyển đổi thành các sơ đồ đồ họa trực quan trực tiếp trên màn hình.
